Google Sheets connection

This app stores all trade data in a Google Sheet you own. Your screenshots go to Google Drive. You keep full control — open the Sheet any time to see your raw data.

console.cloud.google.com → Credentials → Create OAuth 2.0 Client ID → Web application.
Add the URL of this file (e.g. file:/// or your hosted URL) as an Authorised JavaScript origin.
Enable Google Sheets API in APIs & Services → Library.
